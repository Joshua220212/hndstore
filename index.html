PUSAT BANTUAN

FAQ

Jawaban untuk beberapa pertanyaan umum.

Bagaimana cara top up game?

Pilih Mobile Legends atau Free Fire, buka halaman produk, pilih produk yang tersedia, isi data yang diminta, lalu ikuti alur checkout.

Bagaimana cara top up E-Wallet?

Pilih DANA, OVO, atau GoPay. Masukkan nomor dan nominal. Periksa total termasuk biaya admin Rp3.000 sebelum melanjutkan.

Apakah pesanan otomatis dibayar?

Tidak. Menyimpan data pesanan di browser bukan bukti pembayaran dan bukan bukti saldo sudah dikirim. Ikuti instruksi admin dan konfirmasi pembayaran secara langsung.

Kenapa riwayat tidak muncul di perangkat lain?

Riwayat versi ini disimpan secara lokal pada browser yang digunakan. Sinkronisasi lintas perangkat membutuhkan backend/database.

Bagaimana jika salah memasukkan ID game atau nomor?

Periksa kembali data sebelum melanjutkan. Jika pesanan sudah dikirim ke admin, segera hubungi admin untuk menanyakan kemungkinan perbaikan.

Syarat & Kebijakan

📋 Syarat & Ketentuan

  • Periksa kembali ID game, Zone ID, nomor HP, nominal, dan total sebelum mengirim pesanan.
  • Jangan mengirim kata sandi akun game atau kode OTP kepada siapa pun.

  • Konfirmasikan status pembayaran dan pengiriman kepada admin.

🛡️ Kebijakan Privasi

  • Data form disimpan secara lokal pada browser melalui localStorage untuk kebutuhan alur pesanan.
  • Orang yang memiliki akses ke perangkat atau browser tersebut mungkin dapat melihat data lokal.
  • Jangan menggunakan perangkat bersama untuk menyimpan data sensitif.
  • Versi ini belum menyediakan sistem akun, database server, atau sinkronisasi online.
